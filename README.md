# Dashers Finance Manager (PWA)

Static build of the app, ready for GitHub Pages. All paths are relative, so it
works from `https://<user>.github.io/<repo>/`.

## Publish
1. Push this folder's contents to the `main` branch of a GitHub repo
   (the `.github` folder must come with it, so use `git push` or add the
   workflow file in the GitHub web editor if your upload skips hidden folders).
2. Repo **Settings -> Pages -> Build and deployment -> Source: GitHub Actions**.
3. Open the **Actions** tab; when "Publish to GitHub Pages" turns green the site is live.

Every push to `main` republishes. Licensing is OFF in this build (everything unlocked).
